# Costeo de Salsas — PL Cocina

Aplicación de costeo y análisis semanal de salsas preparada para despliegue en GitHub Pages.

## Publicación

El proyecto usa Vite + React y se despliega mediante GitHub Actions a GitHub Pages.

> Nota: GitHub Pages es estático. La versión publicada carga el archivo `data2026.json` incluido en el repositorio. La sincronización directa con Google Sheets que existía en el entorno de Codex requiere un servicio de servidor separado (por ejemplo Apps Script o Cloud Run).
